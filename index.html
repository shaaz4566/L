Welcome to SZC Studio

SZC Studio is an offline-first editor and compiler workspace for the current SZC language prototype.

Quick start

  1. Edit the example in main.szc.
  2. Press Run to compile it.
  3. View the result in Preview.
  4. Download your source or export the project ZIP.
